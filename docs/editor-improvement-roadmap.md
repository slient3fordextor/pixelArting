# 编辑器细节改进清单

这份清单记录像素编辑器的细节缺口、修复顺序和当前状态。每完成一项就更新这里，作为后续开发的持久化任务记录。

状态说明：`[ ]` 未开始，`[~]` 进行中，`[x]` 已完成。

## 绘画工具

- [x] 铅笔和橡皮支持 1..16 像素方形粗细，并记住上次选择。
- [~] 铅笔支持透明度、压力、间距、笔刷形状和自定义笔刷（已完成透明度和方形/圆形笔刷；压力、间距和自定义笔刷待处理）。
- [x] 为画笔和橡皮增加 `[` / `]` 粗细快捷键。
- [x] 同一像素内移动和松开鼠标时不重复落笔，避免单击时叠加画笔不透明度。
- [x] 直线、矩形、椭圆支持 1..16 像素描边粗细，通过滑条和 `[` / `]` 调整，参数独立于画笔并持久化。
- [x] 矩形和椭圆支持描边/填充切换，点击工具图标打开设置。
- [x] 增加 Shift 等比例、直线 45° 吸附、Alt 从中心绘制；拖动时可实时切换约束，Esc 取消且不写入撤销历史。
- [x] 直线、矩形、椭圆在拖动绘制过程中显示实时预览。
- [x] 填充工具支持 0..255 容差、四邻接连续区域和全局同色模式；点击图标或 G 打开设置，参数独立持久化。
- [x] 填充支持当前图层或可见图层合成结果取样，包含图层不透明度；只修改当前图层，遵循选区、锁定和显隐状态，无像素变化时不增加历史。
- [x] 取色器支持当前图层/可见图层合成切换，点击图标或 I 打开设置并独立记忆；原始图层取样忽略图层不透明度，可读取隐藏/锁定层，合成取样遵循显隐和不透明度。透明区域保留当前颜色，重复取色同步色盘且不写入历史。
- [x] 颜色选择器支持 HSB/RGB 数值调整、颜色不透明度、前景色/背景色设置与交换，以及透明色快捷入口；颜色不透明度应用于铅笔、图形和填充，并按本地工作区记忆，取色器会保留采样 alpha。
- [x] 绘图色板支持添加、删除（含空色板）、拖拽排序和按钮排序；按项目自动保存，可恢复默认或载入项目色板。最近 12 个颜色跨项目记忆、去重并可快速复用；色板管理不修改质检规则或撤销历史。

- [ ] 选区支持缩放、旋转、翻转和透视变换。
- [ ] 支持跨图层复制、合并复制和系统剪贴板图片粘贴。
- [ ] 粘贴后支持自由拖动、自动居中和精确定位。
- [ ] 增加浮动选区确认、取消和恢复。

## 画布操作

- [x] 增加适应窗口、填充窗口和自定义缩放：Shift+F 完整显示画布，填充窗口按受限边精确放大并居中，保证整张画布可见；点击百分比输入 5%..1200% 的缩放值，支持一位小数、Enter/失焦确认、Esc 取消，空值或无效输入恢复原比例。导航不修改像素或撤销历史。
- [x] 支持以指针为中心 Ctrl + 滚轮缩放、窗口全局 Shift + 滚轮水平平移（输入控件和弹窗除外）、空格拖动、中键拖动和定位画布（F）；工作区内普通滚轮上下平移画布，可越过画布边缘，空白处也能操作，导航不改变像素或撤销历史。
- [ ] 增加画布导航器或缩略图。
- [x] 网格支持颜色、透明度和间隔调整。
- [x] 支持透明背景样式、背景颜色和棋盘格大小设置。
- [x] 增加像素光标预览，显示当前画笔覆盖范围。
