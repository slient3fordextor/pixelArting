# 本地原型实现状态

本地原型使用 Python 3.12 + FastAPI + Pillow/NumPy，React/TypeScript + Vite，SQLite 与本地文件存储。独立桌面窗口采用 Electron，当前唯一用户入口是桌面客户端；浏览器启动入口已移除。当前不等于完整 MVP，也不具备多用户隔离或云端生成能力。

默认画布为 64×64，目标引擎固定 Godot 4.7.2。运行步骤和限制见 [README](../README.md)。

## 已实现范围

- 绘图色板按项目自动保存，支持添加/删除、拖拽与按钮排序、空色板、恢复默认和载入项目色板；最近 12 色跨项目记忆并去重，支持颜色选择器和取色器同步及快速复用。色板管理不改质检规则或素材历史，连续颜色输入仍使用独立组件的 RAF 更新。
- 颜色选择器支持 HSB/RGB 数值调整、前景色与背景色设置、交换、透明色快捷入口和 0..100% 颜色不透明度；不透明度应用于铅笔、图形和填充并跨会话记忆，取色器读取半透明像素时会同步 alpha。透明色绘制会清除覆盖像素。
- 铅笔增加笔压开关和 10%..200% 间距设置；笔压仅对压感笔指针生效，间距与画笔粗细共同控制连续落点，两项均跨会话记忆。
- 布局支持 Tab 专注画布模式，临时隐藏项目栏、检查器、调色板和时间轴；时间轴可独立折叠并保留帧操作。布局切换不写入像素、缩放、平移或撤销历史。
- 项目栏和检查器可通过顶部按钮独立隐藏或恢复，支持单侧工作区和双侧完全展开画布；相关布局测试通过。
- 项目栏、检查器、工具栏、调色板和时间轴使用统一工作区面板，默认停靠，可最小化、隐藏、浮动拖动、关闭及从顶部/原生“窗口”菜单恢复；布局和浮动坐标持久化，支持恢复默认工作区与边界修正。工具栏包含绘图工具和按当前工具展开的参数，两者保持单行并整体浮动、停靠和关闭，窄窗口横向滚动；铅笔显示粗细、不透明度和形状，橡皮显示粗细和形状并始终完全擦除；点击当前工具可展开或收起参数，浮动栏按内容自适应宽度；画布底部单行提供选区操作、撤销和视图控制。停靠栏目使用纯文字标题和“…”菜单，浮动后才显示窗口图标、停靠及关闭按钮；支持拖出标题浮动和双击标题切换停靠。点击画布后保留，关闭后切换工具不会自动弹出。浮窗位于当前应用内部，暂不支持独立系统窗口、拖拽吸附或自定义分组。另已修复同一像素内移动和松开鼠标重复落笔导致单击不透明度叠加的问题。

- 取色器支持当前图层原始 RGB/可见图层合成切换，参数独立持久化；透明区域保留当前颜色，可读取隐藏或锁定层原始像素。修复重复取同色时色盘显示未同步的问题，取色不修改草稿或撤销历史。

- 填充工具支持 0..255 容差、四邻接连续区域/全局同色、当前层/可见图层合成取样。填充受选区、锁定及图层显隐限制，只写当前层；没有像素变化时不增加撤销记录，设置自动保存到本地。

- 画布观察支持适应窗口、按受限边精确缩放且完整显示画布的居中填充窗口和点击百分比输入精确缩放（5%..1200%，一位小数）；Enter/失焦确认，Esc 取消，无效文本恢复原比例，范围外数值取边界。填充窗口受 1200% 上限限制；这些操作不创建编辑历史。

- PNG 输入、支持边距/间距/行列数与预览的 Sheet 切分、项目与素材管理。
- 动画时间轴支持正向、反向和往返播放；播放方式属于工作区预览设置，不改变已保存的动作帧顺序和时长。
- 画布显示设置支持棋盘格/纯色背景、背景颜色和棋盘格大小，以及像素网格颜色、透明度和间隔；设置保存在本地工作区，不写入像素数据。
- 新建自定义尺寸的透明素材、复制图层、画布/图层/帧/素材区右键操作；素材项与素材栏空白处菜单已分开。
- 首期像素工具已覆盖铅笔、橡皮、取色、填充、直线、矩形、椭圆、矩形选区、画布移动和单图层拖动，并支持 `B/E/I/G/L/R/O/M/H/V` 快捷键；铅笔和橡皮支持 1..16 像素粗细、本地记忆选择及 `[` / `]` 调整粗细，铅笔支持 1..100% 不透明度与方形/圆形笔刷并记住选择，工具选项面板显示铅笔或橡皮设置，画布上会显示当前笔刷覆盖范围，直线、矩形和椭圆支持独立的 1..16 像素描边滑条与本地记忆，矩形/椭圆支持描边或填充；图形设置随工具选项切换，Shift 约束比例或直线 45° 方向，Alt 中心绘制，Esc 取消预览，松开鼠标记一次编辑。选区支持创建、拖动、方向键单像素移动、复制、剪切、粘贴、删除、合并复制、最近邻缩放、90° 旋转、水平/垂直翻转、精确定位和 Escape 取消；选区编辑只写入活动图层。图层支持拖拽排序、向下合并、合并可见图层和全部帧同步，隐藏/锁定层会被保护，操作支持撤销和保存。原点与基线修改会立即更新画布参考标记，可隐藏，不自动改变像素。

## 与目标架构的区别

接口使用 `/api` 前缀，图层像素以 PNG data URL 传送，在 SQLite 快照中保存；下载包将图层改为包内相对路径。支持应用导出的分层 PNG + JSON ZIP 素材包回导入，以及项目备份 ZIP 恢复；不支持单独 JSON 文件回导入。

检查配置当前保存于桌面窗口 localStorage，报告保存实际执行配置快照；尚未实现项目级配置的跨设备同步。原型的素材像素和版本持久化在本地 SQLite，不能将窗口配置保存视为项目风格已同步。

处理同步执行并有输入上限；worker、Redis、任务状态机、取消和重试将在生成/批处理阶段加入。多用户项目需要先补认证和权限校验，当前服务仅绑定 loopback。

多图层格式使用 `schemaVersion=1.1`。图层全局顺序从底到顶，每帧 `pixels` 必须覆盖所有图层 ID，层图尺寸与帧画布相同；opacity 取 0..255。新增层在未导入的帧中自动建立透明图像。

质检使用可见图层合成结果，隐藏层不参与色数和半透明判定。几何修复处理所有层并同步元数据；颜色和 alpha 修复处理可见层。存在锁定图层时当前修复器拒绝整个修复计划。修复不会合并/丢弃图层；不透明度引起的合成问题可能需要用户调整，不能靠源像素修复保证消除。
