# 键盘快捷键

PixelArting 的快捷键在浏览器预览和独立 Electron 客户端中保持一致。工具快捷键在文本输入框获得焦点时不会抢占原生输入操作。

| 快捷键 | 操作 |
| --- | --- |
| `B` | 铅笔 |
| `E` | 橡皮 |
| `I` | 取色器，并打开当前图层/可见图层合成取样设置 |
| `G` | 填充，并打开容差、范围和取样来源设置 |
| `L` | 直线 |
| `R` | 矩形 |
| `O` | 椭圆 |
| `M` | 矩形选区 |
| `H` | 移动画布 |
| `F` | 定位画布，保持缩放并重置平移；也可点击工具栏“定位画布” |
| `Shift + F` | 适应窗口，调整缩放并重置平移以完整显示画布；也可点击工具栏“适应窗口” |
| 点击工具栏缩放百分比 | 输入 5%..1200% 的自定义缩放值，支持一位小数；Enter 或失焦确认，Esc 取消，无效输入恢复原比例，超出范围取边界值 |
| 点击“填充窗口” | 按宽高缩放比例中较小者精确放大并居中，一边贴合可绘图区域且完整显示画布；受 1200% 缩放上限限制 |
| 鼠标滚轮（画布工作区，含空白处） | 上下平移画布，可继续越过画布边缘 |
| `Ctrl` + 鼠标滚轮（画布内） | 以指针为中心缩放，范围 5%..1200% |
| `Shift` + 鼠标滚轮（窗口全局，输入控件和弹窗除外） | 左右平移当前画布，空白处和侧栏均有效；向下滚动向左移，向上滚动向右移；同时按住 Ctrl 时优先缩放 |
| 按住空格 + 左键拖动 | 临时移动画布，松开后恢复原工具 |
| 按住鼠标中键拖动 | 临时移动画布 |
| `V` | 移动图层 |
| `[` / `]` | 减小 / 增大画笔、橡皮或当前图形工具的描边粗细 |
| 绘制图形时按住 `Shift` | 矩形/椭圆等比例，直线以 45° 为间隔吸附；拖动中可随时按下或松开 |
| 绘制图形时按住 `Alt` | 从起点向两侧中心绘制，可与 Shift 组合 |
| `Ctrl/Cmd + Z` | 撤销画布编辑 |
| `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y` | 重做画布编辑 |
| `Ctrl/Cmd + C` | 复制当前选区 |
| `Ctrl/Cmd + X` | 剪切当前选区 |
| `Ctrl/Cmd + V` | 粘贴当前选区 |
| `Delete` / `Backspace` | 删除当前选区 |
| `Escape` | 取消正在绘制的图形或当前选区；焦点在色板管理区时关闭管理面板并返回管理按钮 |
| `Tab` | 切换专注画布模式，隐藏项目栏、检查器、工具栏、调色板和时间轴；再次按下恢复；工作区面板内用于移动焦点 |
| 浮动面板标题获得焦点时 `Alt + 方向键` | 每次移动浮窗 10px，限制在可见区域内 |
| `Ctrl/Cmd + S` | 保存当前版本 |
| `Ctrl/Cmd + N` | 新建素材 |
| `Ctrl/Cmd + O` | 导入素材 |

绘图工具和当前工具参数合并为单行工具栏，整体浮动、停靠、隐藏及关闭；撤销、选区操作和视图控制位于画布底部。拖出栏目标题可浮动，双击标题可切换浮动/停靠。停靠时不显示窗口图标与关闭按钮，通过标题旁的“…”菜单执行浮动、隐藏和关闭；浮动时显示窗口图标、最小化、停靠和关闭按钮。顶部“窗口”菜单与桌面原生“窗口”菜单可恢复栏目，也可恢复默认工作区。面板操作不改变素材或编辑历史。

桌面客户端还会在应用菜单的“编辑”和“工具”中显示这些快捷键；文本框获得焦点时，撤销、重做和复制粘贴仍交给文本编辑器处理。
