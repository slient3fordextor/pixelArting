# 本地桌面客户端

当前唯一用户入口为独立桌面窗口。桌面外壳使用 Electron 44.7.0，编辑器使用 React/TypeScript，核心图片处理使用 Python/FastAPI；React 构建产物只在 Electron 窗口内加载。Go 不进入当前实现；桌面窗口需求不要求把图片处理逻辑重写为另一种语言。

## 启动和数据

安装步骤见 [README](../README.md)。`desktop/start.sh` 打开原生窗口，无需用户手动启动后端或浏览器。桌面进程选择空闲的 loopback 端口并等待 `/api/health`，失败时显示启动错误；窗口关闭后停止自己启动的服务。开发时使用 `desktop/start-dev.sh`，桌面进程会额外启动 Vite，并把 `/api` 代理到自己的后端端口；保存前端代码后由 Vite HMR 更新窗口，无需重启 Electron。该模式仅用于开发，普通启动仍加载 `frontend/dist`。

默认使用工作区 `data/`，`PIXELART_DATA_DIR` 可指定其他目录，`PIXELART_PYTHON` 可指定已经安装依赖的 Python 可执行文件。桌面用户配置位于 Electron 的 userData 目录；`PIXELART_DESKTOP_USER_DATA` 用于隔离测试。调色板配置保存在桌面窗口的 localStorage，素材和版本保存在本地数据目录。

当前是工作区可启动客户端，依赖项目虚拟环境和已构建的前端。Linux 启动文件使用当前工作区绝对路径；Windows/macOS 安装包、Python 运行时打包、自动更新、签名和图标发布暂未实现，不应把它称为已经完成的跨平台分发包。

## 素材和图层

按 `Tab` 可切换专注画布模式。该模式暂时隐藏项目栏、右侧检查器、调色板和时间轴，让画布获得完整工作区；再次按 `Tab` 恢复。模式切换只改变布局，不改变缩放、平移、工具参数、像素或撤销历史。时间轴标题右侧的折叠按钮可以单独收起帧缩略图和动画参数，保留新建、复制、删除帧等操作。

顶部的左右面板按钮可以独立隐藏项目栏或检查器，适合只需要素材列表、只需要图层属性，或两侧都暂时不需要的场景。恢复面板不会重置画布位置、缩放或当前工具。

工作区采用可管理的停靠面板：项目栏、检查器、工具选项、调色板和时间轴。标题栏依次提供最小化、浮动/停靠、隐藏和关闭按钮；侧栏最小化为图标条，其他面板缩为标题栏，时间轴保留帧操作。点击标题图标或展开按钮恢复内容。隐藏和关闭仅移除面板显示，不删除素材或工具参数。

工具选项默认停靠在工具栏下方，切换绘画工具只更新相应参数，点击画布后继续保留。隐藏或关闭工具选项后，切换工具不会重新打开，需从顶部“窗口”菜单或桌面原生“窗口”菜单恢复。浮动由用户主动切换，拖动标题文字区域可移动；标题获得焦点后可用 Alt + 方向键每次移动 10px。浮动面板点击外部不会自动关闭，Esc 保留图形取消或选区取消等原有语义。

“窗口”菜单可显示/隐藏各面板，并提供“恢复默认工作区”。原生菜单中的各面板项用于显示或恢复。停靠/浮动、最小化、隐藏/关闭和浮动位置保存在窗口 localStorage；重启后恢复，损坏布局回退到默认，缩小窗口时浮动面板自动移回可见区域。恢复面板和重置工作区会退出 Tab 专注模式；面板内部按 Tab 在控件间移动焦点。当前浮窗是应用窗口内部的可拖动面板，使用停靠按钮回到固定原位；尚不支持拖到另一个显示器的独立系统窗口、拖拽吸附或自定义面板分组。

缩放百分比可点击编辑，范围 5%..1200%，支持一位小数。Enter 或失焦确认并重置平移，Esc 取消；空白或无效文本恢复原比例，超出范围时取边界值。“适应窗口”完整显示画布，“填充窗口”取可用宽度/画布宽度、可用高度/画布高度两者中较小的比例，精确放大并居中，保证整张画布可见；“适应窗口”优先使用整数倍率，“填充窗口”支持小数倍率以尽量贴合其中一边；填充受 1200% 上限限制。缩放输入期间保留原生文本操作，不触发画布快捷键。

新建素材默认 64×64，可以设置 1..512 的宽高。后端创建单帧、一个透明 RGBA 图层和初始不可变版本，记录 `provenance.kind=created`，不伪造上传来源。接口为 `POST /api/projects/{projectId}/assets/blank`，输入 `name`、`width`、`height`；尺寸和项目归属必须通过校验。

PNG 可以作为独立素材上传，也可以导入为新图层。新图层的 PNG 必须与当前帧尺寸一致，其他帧自动建立透明图像；没有隐式缩放、裁剪或图层合并。图层复制覆盖所有帧，生成独立图层 ID，保留可见性和不透明度，副本解除锁定。图层和帧操作仍走原有草稿、撤销重做和版本保存。

编辑草稿会按素材 ID 保存在桌面窗口的 localStorage 中，停止编辑约 600 ms 后自动写入，并记录草稿创建时的正式版本 ID、当前帧和选中图层。重新打开或切换到素材时，只有正式版本 ID 仍一致才提示恢复；选择丢弃会删除本地草稿，选择恢复后内容仍标记为未保存，必须显式点击“保存”才创建正式版本。自动保存失败只影响恢复副本，不会覆盖 SQLite 中的正式版本；窗口关闭前会尽力补写一次草稿。

在画布上按住 Ctrl 滚动鼠标滚轮可围绕指针缩放，范围为 5%..1200%；工作区内普通滚轮上下平移画布，可越过画布边缘，空白处也能操作。Shift + 滚轮在窗口全局左右平移当前画布，鼠标位于空白处或侧栏时也有效，输入控件和弹窗除外；即使画布小于工作区或已移出视野也有效；向下滚动向左移，向上滚动向右移，同时按住 Ctrl 时优先缩放。按住空格加左键或直接按住中键可临时拖动画布，松开后保留原工具；拖动时指针显示为抓手。工具栏“定位画布（F）”保留缩放、恢复画布位置并清除工作区滚动偏移；“适应窗口（Shift+F）”根据可用工作区重新计算缩放并重置平移，支持低于 100% 显示大画布。导航不改变图像或撤销历史，绘制途中 Ctrl + 滚轮不会改变缩放；输入框中的空格保留正常输入，窗口失焦会清除临时导航状态。

素材列表始终展示真实缩略图，选中项显示当前草稿帧，其他项显示当前保存版本的首帧，透明部分用棋盘格表示。缩略图接口 `GET /api/assets/{assetId}/thumbnail?versionId=...` 使用最近邻缩放且保留长宽比；版本 ID 变化后请求新图，避免复用过期预览。

每项提供删除按钮，右键素材也可删除。`DELETE /api/assets/{assetId}` 接收 `expectedCurrentVersionId`，先确认不可撤销删除，再以数据库事务删除该素材、全部版本、报告和修复预览；版本不一致返回 409，其他素材保持不变。原始 PNG 的哈希文件暂不自动清理，因为文件可能被多个素材共用；删除不承诺立即释放这部分磁盘空间。删除当前素材后切换到其他项，删完后回到空工作台。

## 右键操作

下表记录当前实现。素材对象和空白区的独立菜单、应用内素材复制粘贴及重命名的设计依据见 [素材栏交互调研](asset-library-interactions.md)。系统剪贴板、搜索、标签和回收站仍是后续候选。

| 区域 | 操作 |
|---|---|
| 素材栏空白处 | 新建素材、导入 PNG/Sheet、粘贴素材、刷新列表、新建项目 |
| 素材 | 打开、重命名、复制素材、创建副本、导出当前帧/分层包、查看版本、删除 |
| 画布 | 铅笔、橡皮、取色、填充、直线、矩形、椭圆、矩形选区、移动画布、移动图层、撤销、重做、新建/导入图层、清空当前帧选中层、像素网格 |
| 图层 | 重命名、复制、显隐、锁定/解锁、上下移动、新建/导入层、删除 |
| 帧 | 复制、删除、前移、后移；当前动作映射的帧时长显示在缩略图上 |
| 桌面文本输入 | 原生剪切、复制、粘贴、全选和文本撤销/重做 |

右键图层操作针对点击的图层，帧操作针对点击的帧。锁定图层不能重命名、移动、删除或清空；最后一个图层和最后一帧不能删除。修复预览、动画播放及处理期间禁用编辑。清空或删除图层先确认；关闭桌面窗口时有未保存编辑也需要确认。

菜单在视口边缘自动调整位置，可用方向键、Home/End、Enter 和 Escape 操作；点击外部或滚动关闭。素材名称支持双击进入内联编辑，也可通过素材右键菜单进入同一编辑状态；Enter 或失焦保存，Escape 取消。文本输入保留原生编辑菜单。桌面菜单提供新建、导入和保存，导出使用系统保存对话框。

## 取色性能

画布下方色板提供“+”添加当前颜色和“管理色板”入口。色块可拖拽排序，管理面板也可前移/后移当前色块、删除当前色块、恢复默认或载入项目色板；面板内按 Esc 关闭并返回管理按钮。面板浮在色板上方，不额外压缩画布空间。删除色块保留当前绘图颜色，删除最后一个色块后保持空色板，可继续添加。

绘图色板按项目保存在桌面窗口 localStorage（最多 256 色），项目间相互独立，不写入素材或修改质检调色板。未自定义时沿用项目调色板，没有项目颜色则显示默认色板；开始自定义后可以通过“载入项目色板”主动同步。最近 12 个颜色跨项目保存，选择色块、确认颜色选择器或使用取色器会更新记录，同色去重并移到最前，可直接点击复用。连续拖动颜色选择器只在确认/失焦时记忆最终颜色，损坏的本地数据会回退或过滤无效颜色。

连续拖动颜色选择器只更新独立调色盘组件，画笔通过 ref 立即读取最新值，色号和选中色块以 requestAnimationFrame 合并更新。取色不改素材、历史或质检状态，也不会触发整个工作台重渲染。

### 绘图工具

点击取色器（I）打开独立的取样设置，默认使用“可见图层合成”，可切换为“当前图层”，选择自动保存且与填充工具互不影响。当前图层读取原始 RGB，不受该层不透明度、显隐、锁定或选区限制；合成取样包含可见图层的不透明度，不包含洋葱皮、网格及参考线。只取 RGB，不修改画笔不透明度；取样像素完全透明时保留当前颜色。取色不修改图像、草稿状态或撤销历史；重复取同一个颜色也会同步色盘、色号与后续绘图颜色。

点击填充图标（G）打开设置，可选择容差 0..255、“连续区域”或“全局同色”，以及“当前图层”或“可见图层合成”取样。连续区域只连通上下左右，容差按像素与点击位置的 RGBA 各通道差值判断，不逐步扩散到更远的颜色；全透明像素忽略隐藏的 RGB 值。合成取样包含可见图层的不透明度，不包含洋葱皮、网格或参考线；所有填充只写入当前图层并受选区裁切，从选区外点击不执行，隐藏或锁定层不写入。填充颜色使用当前绘图颜色并以完全不透明像素替换，不沿用画笔不透明度。一次填充只记一次撤销；同色重复填充等没有像素变化的操作不增加历史。参数保存在桌面窗口 localStorage，损坏的配置回退到默认设置。

工具栏和画布右键菜单提供首期像素绘图工具：铅笔 `B`、橡皮 `E`、取色 `I`、填充 `G`、直线 `L`、矩形 `R`、椭圆 `O`、矩形选区 `M`、移动画布 `H` 和移动图层 `V`。直线、矩形和椭圆支持 1..16 像素描边滑条及 `[` / `]` 快捷键，矩形和椭圆可切换描边/填充。工具选项面板显示当前工具设置，图形参数独立于画笔并保存在 localStorage。拖动实时预览，Shift 约束矩形/椭圆等比例或直线 45° 方向，Alt 从中心绘制，两者可组合并在拖动中切换；Esc 取消，松开鼠标记一次撤销历史。选区会限制后续像素编辑；取色器按所选来源读取颜色并回写调色盘。选区支持拖动、方向键单像素移动、复制、剪切、粘贴、删除和 Escape 取消；当前操作作用于活动图层，复杂选区、缩放、羽化和跨层变换留在后续阶段。

画布编辑支持 `Ctrl/Cmd+Z` 撤销、`Ctrl/Cmd+Shift+Z` 或 `Ctrl/Cmd+Y` 重做。文本输入框保留浏览器原生的文本撤销行为。编辑停止约 600 ms 后会自动保存本地草稿；草稿绑定正式版本号，恢复后仍须显式保存。

移动图层也可从图层右键菜单选择。在画布中拖动时，只平移当前帧选中图层的全部像素，不改变其他图层、帧或帧元数据；选区不裁切移动范围。拖动按整数像素对齐，实时预览，松开记一次草稿编辑，支持撤销、重做和保存；拖动过程中按 Escape 可取消。位移受有效像素边界限制，不允许拖出画布而丢失内容；空图层和零位移不记录编辑，锁定或隐藏图层不可移动。移动画布只改变观察位置，不修改素材。

帧属性中的原点、基线是参考元数据。画布以十字参考线和圆形锚点显示原点，以水平虚线显示基线；修改输入会立即移动对应标记。工具栏的“帧参考线”开关可以隐藏这些标记；它们不写入 PNG，也不会自动平移角色像素。跨帧像素对齐仍通过基线对齐修复的预览和提交执行。

在本机 Chromium、64 帧场景中，一批 120 次连续颜色事件原耗时约 125..217 ms，调整后约 2..4 ms。该测量覆盖事件处理，不等同于所有操作系统原生颜色对话框的帧率保证；回归测试还验证最后选中的颜色确实用于下一笔绘制。

## 桌面边界

窗口只加载本机服务，关闭 Node integration，启用 context isolation、renderer sandbox 和 webSecurity，设置 CSP，限制新窗口与跨站导航，不向页面暴露 Node 或文件系统接口。权限请求默认拒绝，桌面服务只绑定 `127.0.0.1`。

实现约束参考 [Electron 官方安全文档](https://www.electronjs.org/docs/latest/tutorial/security)。这些窗口配置不替代多用户认证、云端部署权限或未来引擎插件的访问控制。

## 验证

本机 Linux 原生 Electron 窗口启动和 Playwright 回归已验证：64×64 画布非空，Node integration 关闭，sandbox/context isolation 启用；右键菜单可用，原生菜单能创建素材和保存，素材双击/右键重命名、图层拖动和帧参考标记可用，未保存时选择继续编辑会保留窗口和草稿，关闭后专属服务不可访问。渲染界面回归还验证文件图层导入、连续取色、真实缩略图、删除确认、素材菜单区分、完整快照复制粘贴，以及图层拖动的跨层/跨帧隔离、边界保护、撤销、保存重载和锁定保护。Windows/macOS 尚未执行对应验证。

22 项 Electron 导航与绘图交互用例覆盖窗口全局水平平移、越过画布边缘的垂直平移、临时拖动、快捷键焦点隔离、图形粗细与填充、参数重载、实时 Shift/Alt 约束、选区裁切、取消操作、大画布适应窗口（含缩小窗口后重新适应）、宽/长画布居中填充、精确缩放的确认/取消/无效输入与范围边界，以及填充容差、四邻接/全局匹配、透明度、合成取样隔离、选区/锁定/隐藏保护、无变化历史和配置重载，以及取色来源切换、保护层读取、透明取样、重复取色同步和独立参数持久化。新增色板测试验证真实拖拽和按钮排序、删除至空色板、项目隔离、质检规则隔离、重载记忆、最近 12 色、连续输入只记最终颜色、损坏数据过滤和 256 色上限。

工作区通过画布变换执行导航，禁用原生程序滚动，避免画布被裁切时自动滚动立即关闭右键菜单。渲染端 390px 布局与连续取色回归通过。最终完整桌面回归 25 项中 24 项通过，临时平移出现一次位移偏差；另一次取色器测试出现对话框协议异常。两项各自独立重跑三次通过，根因仍待查，详情与此前偶发问题见 [实现状态](implementation-status.md)。
