# AI 素材生成

工作台顶部的「AI 生成」入口提供两种模式。两种模式均需配置用户自己的服务和 API Key；项目不创建密钥，也不提供免费模型服务。

## 模式

| 模式 | 请求 | 处理结果 |
| --- | --- | --- |
| 像素工具绘制 | 文本模型把描述转换成 JSON 绘画命令 | 本地执行命令，生成可编辑图层、帧和元数据 |
| 图像模型生成 | 图像模型按描述返回 PNG | 保存原图，缩放、降色并转换为像素素材 |

像素工具绘制仍需要 LLM，但不调用图像生成模型。目前每次生成只请求一批命令，没有自动观察画面、反复修画的循环。模型不能执行任意代码；仅能使用画布、图层、调色板、矩形、直线、区域填充、像素批量绘制、帧复制、镜像、原点、碰撞框和质量检查这些工具。

图像模式使用最近邻缩放和无抖动降色。透明选项保留已有透明度并将 alpha 二值化，不会自动删除模型生成的实色背景。原始 PNG 可从候选旁的下载按钮获取。

## 服务设置

在生成面板的「连接设置」中填写 Base URL、API Key、文本模型、图像模型和图像服务生成尺寸。Base URL 应包含服务的 API 前缀，例如 `https://api.openai.com/v1`。文本和图像请求共用这个地址与密钥，模型名称分别设置。

连接设置支持保存多个命名的「模型档案」。每个档案独立保存 Base URL、API Key、文本模型、图像模型、图像尺寸和高级兼容参数；从档案下拉框切换后，后续生成会使用新的档案。档案名称必须唯一，当前档案需要先切换到其他档案后才能删除。旧版本只有一份连接设置时，首次启动会自动迁移为「默认配置」档案。

接口采用 OpenAI-compatible 格式：文本请求 `POST chat/completions`，要求 JSON 输出；图像请求 `POST images/generations`，接受 `b64_json` 或 PNG 下载地址。服务需要支持对应接口，只有相同的模型名称并不代表兼容。

「高级设置」可配置文本输出 token 上限、`max_tokens` / `max_completion_tokens` 参数名称，以及是否发送图像 `background` 参数。不同服务对这些参数和图像尺寸的支持可能不同，需要按服务要求配置。

API Key 输入框在保存或关闭后清空，留空保存会保留已有密钥，旁边的删除按钮可清除已保存密钥。密钥保存于当前数据目录的 SQLite 中，数据库文件权限限制为当前用户；它没有进行静态加密，也未接入系统钥匙串。密钥不会进入浏览器存储、任务响应、项目备份或素材导出。配置适用于本地单用户工作台，不能直接将后端开放给多人共用。

## 生成与导入

填写描述、像素宽高、候选数量、颜色上限和透明选项后生成。任务记录按项目保存，任务可取消，失败或取消后可使用原请求重试，也可按当前表单重新生成。

生成成功不会自动改变当前素材。选择候选并导入后，才会创建新的素材和正式版本；当前编辑尚未保存时会先进行确认。重复选择同一个任务的同一个候选导入到同一项目，不会创建重复素材。

关闭生成面板不会取消后台任务。取消是本地任务状态取消，无法保证撤回已经发出的服务请求，也不保证服务商停止计费。候选处理期间取消可能仍完成原图下载；任务结果不会恢复为成功。应用重启后无法续接旧请求，未完成的任务会标记失败，可手动重试。

生成任务创建时会保存所选档案的配置快照，因此切换档案不会改变已经排队或正在执行的任务；重试会使用重试时当前激活的档案。生成费用由用户所选服务收取。工具绘制按文本模型的 token 计费规则收费；图像模式按服务商的图像计费规则收费。输出 token 上限不是总费用上限，重试也可能再次产生费用。本项目没有自动计价或扣款功能。

## 当前边界

像素画布支持 1 到 512，候选数量最多 8，颜色上限最多 256。绘画候选最多 500 条命令、64 帧、16 图层，并检查坐标、颜色和像素预算。图像候选必须是静态 PNG，原图最多 8 MB、2048×2048。

命令合法和规则检查通过不代表画面质量达到游戏素材要求，也不保证动作完整、风格一致或版权状态确定。AI 素材记录来源、模型和描述，版权状态默认为未知。

开发验证使用本地模拟 AI 服务，覆盖前后端请求、候选渲染、确认导入和失败重试。没有使用真实密钥发起收费请求；用户配置的具体服务仍需实际连接验证。
